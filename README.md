# کاتالوگ برنامه‌ها

صفحه اصلی کاتالوگ است و داده‌ها را از `index.json` می‌خواند.

## ساختار ریپو
```
index.html
index.json            ← فهرست آیتم‌ها (اینجا ویرایش می‌شود)
manifest.webmanifest
sw.js
.nojekyll
icons/
```

## افزودن یا ویرایش آیتم
**روش ۱ (پنل مدیریت):** صفحه را باز کنید ← ⚙️ مدیریت ← آیتم را اضافه یا ویرایش کنید ← «خروجی index.json» ← متن را کپی کنید ← در گیت‌هاب فایل `index.json` را با آیکن مداد باز کنید، همه را جایگزین کنید و Commit بزنید ← در صفحه «حذف پیش‌نویس» را بزنید.

**روش ۲ (دستی):** مستقیم `index.json` را ویرایش کنید. هر آیتم:
```
{ "slug": "leitner", "name": "...", "cat": "...", "tags": ["..."], "desc": "...",
  "icon": "🧠", "color": "#7c4dff", "url": "https://USER.github.io/REPO/", "feat": true, "date": "2026-10-21" }
```
`url` آدرس خود برنامه است. هر برنامه ریپو، manifest و service worker جداگانه دارد.

## انتشار
Settings ← Pages ← Deploy from a branch ← شاخه `main` و پوشه `/ (root)`.

## به‌روزرسانی کش
اگر `index.html` یا آیکون‌ها را تغییر دادید، مقدار `V` در `sw.js` را بالا ببرید. تغییر `index.json` خودکار و فوری دیده می‌شود.

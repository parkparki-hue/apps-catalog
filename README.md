# کاتالوگ برنامه‌ها (بخش کاربر)

این ریپو فقط **نمایش** است. هیچ کد مدیریتی یا توکنی در آن نیست.

## ساختار
```
index.html            ← صفحه کاربر (فقط مشاهده)
index.json            ← فهرست آیتم‌ها
manifest.webmanifest
sw.js
.nojekyll
icons/                ← آیکون خود کاتالوگ
assets/icons/         ← آیکون آیتم‌ها (توسط پنل مدیر ساخته می‌شود)
```

## مدیریت
فایل `catalog-admin.html` **داخل ریپو نیست** و فقط روی دستگاه خودتان نگه داشته می‌شود.
- مدیر با GitHub API مستقیم `index.json` و تصویر آیتم‌ها را commit می‌کند.
- امنیت از توکن شخصی (Fine-grained، فقط همین ریپو، Contents: Read and write) می‌آید، نه از مخفی بودن صفحه.
- آیتمی که `"draft": true` دارد برای کاربران نمایش داده نمی‌شود.

## انتشار
Settings ← Pages ← Deploy from a branch ← `main` و `/ (root)`.

## کش
اگر `index.html` یا آیکون‌ها را عوض کردید، `V` در `sw.js` را بالا ببرید. تغییر `index.json` فوراً دیده می‌شود.
